## Findings

### 🟡 Warning

**T5 Coverage Illusion — Smoke check swallows assertion failures (Warning)**

Symptom: `existing.test.mjs` wraps both assertions in `try { ... } catch {}`. An assertion failure throws, but the empty catch consumes it.

Source: *How Google Tests Software* — meaningful verification; *The Art of Unit Testing* — test completeness.

Consequence: The supplied `contract.md` requires this local smoke check to exit unsuccessfully when its own assertion fails. The current check can instead exit successfully, so it cannot reliably signal a regression detected by either assertion. This is a local defect; the effect on any broader suite is unknown.

Remedy: Remove the empty catch so assertion errors propagate and make the process exit unsuccessfully.
