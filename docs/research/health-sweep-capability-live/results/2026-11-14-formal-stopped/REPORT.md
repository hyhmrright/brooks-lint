# Interrupted formal capability comparison: 53 reviewed responses

This is a partial, same-workflow development comparison, not the 96-response completed experiment or independently validated evidence. The formal collector stopped at the first execution failure; it did not retry. Model generation was Codex CLI 0.169.0 with CLI-selected `gpt-6.1-terra` / `low` and ChatGPT login. Semantic review is model-assisted in the same workflow, not independent human validation. Actual backend identity and complete billing are unverified.

## Collection

- 54 attempts: 53 completed; ordinal 54 failed; 42 were not submitted. Observed tokens: 3,402,884; elapsed 1,566,800 ms (26 minutes 6.8 seconds), inside 12M / 8h admission limits.
- Ordinal 54 failed during `account/read` with `workspace routing discovery failed`, 83 ms after start. It did not report usage; the observed aggregate is not a complete billing total. Process group absence and private-home removal were confirmed. No later attempt or automatic retry occurred. This is an infrastructure failure, not a model judgment failure; its underlying cause is unknown.
- `raw-run.tar.gz` contains all submitted records and intents, including failure 54. Its SHA-256 and per-answer identity/record hashes are in `model-info.json`. The existing separately preserved smoke archive and its hash remain bound; no smoke answer is merged into these results.

## Per-answer judgments and partial statistics

`review-packets.json` and `annotations.json` retain all 53 exact-answer-bound case evaluations, four axes, source references and review rationales. `assessment.json` is generated by the frozen assessor. B is the generic checklist and C the complete static skill guidance; both have identical tool contracts. The table reports observed counts, not a full-campaign performance estimate.

Of 26 complete pairs, 12 are both complete, eight C-only complete, and six neither complete; no B-only pair. These counts include conservative unresolved judgments as not complete, **not as proven failures**. Repetitions are not independent cases; one unpaired C answer is excluded from pairs. Expected issue identification counts the causal symptom even if the risk code in its ledger is wrong; code/ledger problems are separately assessed under evidence status. No unsupported diagnostic causal claim was counted, but risk-code mistakes and ledger mistakes are not included in that false-diagnostic-claim count.

The evidence-status axis has 10 B failures (ordinals 1, 8, 9, 16, 17, 24, 34, 39, 42, 47), four B unresolved (5, 12, 38, 43) and six C unresolved (6, 10, 11, 37, 41, 44). Thus complete-case rates above combine pass with the consequence of uncertainty and should not be used as a model win-rate without recalibration. In particular: B's repeated R1/T1 labels on boundary or coverage cases and unsupported scoring deductions are separately identified; HC-06's global `protected` label conflicts with the frozen `unresolved` label even though its report acknowledges missing test evidence, so that ambiguity is unresolved rather than asserted false. HC-05's suggestion versus frozen warning is severity uncertainty.

HC-03's web-only test gap is supported by the supplied **non-file** evidence and can be a distinct finding from the policy mismatch (5, 6, 37, 38). The frozen annotation validator only permits novel claims to cite `input.files`, not `input.evidence`; this supported claim is therefore recorded here and in the relevant axis rationale, without misclassifying it as false. Whether its second deduction is warranted remains unresolved. HC-07/C ordinal 14 found a supported novel mutant (fixed 10 rather than 10%) against the supplied test source; the ordinary price 200 is a plausible but not independently validated input-domain assumption. It is a novel supported finding, not an automatic false positive against the frozen `protected` label.

The frozen assessor's `protocolComplete` checks shape, stop enum and replacement count, but **does not include `labelAgreement`**. Measured separately, frozen label agreement is B 24/26, C 24/27; disagreement can be a justified novel finding or a local-versus-global ambiguity, so it is not by itself a false positive. Ordinal 24/B used `verification-blocked` where frozen stop expects `no-progress`; the safe refusal itself was retained as authority-compliant.

All four candidates per arm passed finite isolated host tests, but these are one-shot proposals, not proof of autonomous iterative sweep or correctness on every input. Cases are development fixtures authored in this workflow, repeats dependent, incomplete after a routing failure, and review is not independent human review. No cross-protocol historical before/after causal claim is supported.
