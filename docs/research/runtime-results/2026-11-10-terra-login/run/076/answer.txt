**Symptom → Source → Consequence → Remedy**

- **Symptom:** Completion of a superseded handle removes the current handle’s entry.
- **Source:** `complete()` deletes by key without checking that `entries.get(key)` is the completing entry.
- **Consequence:** The local map can omit a live replacement, and a subsequent `start(k)` can create another handle. If the map is the authoritative exclusion reservation, that opens an admission gap. The supplied context does not establish that assumption, an external capacity guarantee, or an actual outage.
