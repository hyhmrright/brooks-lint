# Capability corpus v1: offline development preparation

This expands the historical regression suite without changing its sources, labels or results. It contains eight health and six sweep cases, covering dependency direction, policy ownership, mutant survival, configuration defaults, parsing, unknown cache contracts, protocol authorization, deployment replay and zero-round disposition. These are same-workflow authored development fixtures, not independent holdouts.

## Measurement

B receives a generic checklist and C a full static instruction bundle: its SKILL.md, shared setup framework and remedy guide, its mode guide, plus all five focused pass guides required by sweep. The explicit ordered inventory is `instructionFiles` in `suite.mjs`. No fixture defines custom risks; conditional project-specific custom-risk material is not applicable. This bundles instruction text but does not simulate native discovery, interactive file reads or execution. The task, tool contract and edit authority are identical. Private rubric, reference candidates and evaluator tests are not appended by the assembler. Tests visible in a fixture are ordinary public test inventory, not secret evaluator answers. Expected issue lists guide review; a novel finding needs causal evidence and is not automatically a false positive.

Record diagnosis, evidence/status validity, action/authority, reporting honesty, exact stop-enum agreement, delivery and repair outcome separately. A safe refusal with the wrong enum may fail protocol compliance while passing authority. Aggregate by mode and family, with repetitions reported separately from independent cases. Manual judgment remains necessary: the annotation validator checks completeness, not semantic truth. The ledger helper checks arithmetic and unique causal ownership after semantic admission; it is not a replacement for the shipped scorer.

Health premises include a forbidden import, divergent shared policy and an escaping mutant, with protected and unknown counterparts. HC-08 supplies complete evidence and a single causal finding cross-referenced across dimensions: architecture owns the deduction. Its explicit equal-weight benchmark contract yields 98.75; this is not a claim about shipped default weights. Other health cases suppress composites where required evidence is missing. Strictness and duplicate causal ownership are separately tested. This remains a small development corpus, not comprehensive coverage.

Sweep reference candidates exercise a useful fix, no-op, overbroad regression and unauthorized sentinel edit. Known reference code runs in disposable temporary directories with an empty credential environment, a two-second deadline, output cap and Node permission restrictions. Only named authored references are accepted. This is **not** a security boundary for arbitrary generated code. Untrusted model candidates are deliberately unexecutable here until a container/workspace isolation design and live protocol are frozen. A host checking a candidate is not evidence that the model executed the sweep itself.
