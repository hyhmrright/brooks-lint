# Exploratory startup and routing failures

These original per-attempt records precede the final frozen implementation. Each
captures its own declared argv/environment/policy, original streams and local
HTTP observations. Per-attempt source snapshots were not frozen, so no exact
source-reproduction claim is made. Early initial_home_empty booleans are
declarations; final cases instead record actual directory listings.

All retained attempts had zero received stub requests. They demonstrate startup
or routing failure under confinement, not no-retry conformance. Private preference
environment spellings, proxy environment and inline feature settings evolved
across the named attempts; no file has been normalized to the final settings.
