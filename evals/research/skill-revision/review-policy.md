# Three-skill revision comparison — prospective review policy v1

Freeze this policy, the cases, the original and revised guide snapshots, and the
executor before any response is collected. A is original supplied guidance; B is
revised supplied guidance. Neither arm is a no-skill baseline. Use the same
selected model and effort for every call. The historical no-skill campaign is
context, not a contemporary control for this revision effect.

## Corpus and interpretation

Sixteen historical development cases informed the revisions. Six new boundary
cases were authored in the same workflow after the weakness analysis. Neither
cohort is an independent holdout. Report the two cohorts separately before any
combined within-skill totals. Three repeats remain observations of the same case.
The sweep guidance also embeds revised review guidance, so its change is a bundled
revision effect, not isolation of the sweep guide alone. No native skill loading,
workspace navigation, test execution or autonomous multi-step repair is measured.

The new study retains each historical originalRubric and its immutable baseline
freeze. Its active rubric prospectively accepts semantically equivalent numerical
witnesses in AS-01 and AS-04 and equivalent behavior-preserving renames in AS-35.
Only those evidence strings change; the original values are retained on each case.
A concrete alternative must execute correctly and prove the same causal contrast.
Generic claims, unsupported output values or merely saying "brittle" earn no credit.
New cases similarly specify behavioral evidence rather than arbitrary spellings.
This is a versioned comparison policy, not retrospective correction of old scores.

AS-35's phrase "validated finite nonnegative integer cents" does not unambiguously
assign rejection responsibility. Affirmative new validation/rejection allegations
remain pending unless the supplied contract resolves the obligation; they are not
automatically false merely because absent from expected issues. Questions and
conditional remedies are not affirmative extra defects. In review cases, absent
supplied tests do not by themselves prove an absent project-wide test inventory.
A scoped observation about an attached test is distinct from a claim about all
coverage. Score the semantic claim, not whether it appears beneath a finding title.

## Per-response assessment

Read shuffled review packets before the mapping. Record reviewer identity, model
when known, exposure and method honestly. Masking cannot hide inferable writing
style and is not independent human validation. Every completed answer needs one
annotation containing responseId and review with answerSha256, reviewer,
assessment, assessmentSupport, issues, evidence, unsupportedClaims, pendingClaims,
and novelConfirmedClaims. Every credited element and claim requires an exact
nonempty answer excerpt and rationale. Confirmed extra claims require independent
fixture adjudication/reference. Preserve initial and final decisions on disputes.
List missing evidence with its index and reason; do not award evidence by keyword.

Diagnostic outcomes: defect/protected/unresolved/out-of-scope/no-answer. Task
criteria outcomes: completed/partial/unresolved/out-of-scope/no-answer. Do not
count arithmetic or workflow criteria as bug recall. A correct rounded score with
incorrect intermediate arithmetic is not a complete dashboard. An inconsistent
headline is a separate confirmed error. Unassessed dimensions are not clean ones.

For each sweep answer the frozen bounded artifact oracle checks the complete JSON
value, edit paths, behavior and preservation without executing generated source.
Malformed envelopes, unauthorized edits, no-op defective repairs and behavior
failures remain task failures in the denominator. A syntax pass alone is not repair
success. Explicit task-specific report-string requirements are semantic criteria
in addition to the generic artifact oracle, and must be checked individually.

## Results and admission gate

Report A/B within each skill and cohort: execution failures/not-run, disposition,
expected-issue recall and misses, task criteria, causal evidence, unsupported and
pending claims, precision bounds, control errors, artifact success, complete
supported responses, repeat and paired results, observed tokens and duration.
Pending allegations leave complete support unresolved; do not force success/failure.
Do not pool these dimensions into a single campaign accuracy. Label reproducibility
checks as arithmetic and provenance validation, not independent semantic truth.

Descriptive retain criterion per skill: at least one targeted metric improves
without a new confirmed false-positive response, control error or artifact failure
relative to the original arm. Report mixed or no detectable gain otherwise. With
small exposed cases, neither outcome proves production generalization. Do not tune
skills or labels during the run; use a new version for subsequent changes.

132 primary calls = 22 cases × 2 arms × 3 repeats. Admission stops at 5,000,000
observed tokens or eight elapsed hours; per-turn deadline is at most 180 seconds.
Zero automatic retries. Usage stops are between turns and can overshoot one turn;
unknown failed usage and provider-internal retries are not billing-capped. First
execution/identity/cleanup/usage failure stops new admission and preserves evidence.
Preparation and offline simulation do not authorize calls. Explicit registration,
selected model/effort and --live are required; no separate judge calls are implied.

## Completed-message collection contract

This new study uses the repaired collector. Only item/completed agent messages
from the bound thread and turn enter the answer. Preserve every completed phase,
including commentary and absent/unknown phases, in completion order; identical
retransmissions deduplicate and conflicting completions fail closed. Orphan stream
deltas are excluded from the answer and retained separately as partial diagnostics.
A successful transport turn with no nonempty completed answer is an execution
failure. The raw record records the selected IDs, phases, text hashes and excluded
partial items. The run verifier independently reconstructs this selection.

An abandoned draft concatenated by a collector is not a model-format error. A
legitimately completed commentary message outside a required JSON object remains
in the answer and can be a real output-contract failure; do not silently discard
it. The original campaign correction is separately versioned and leaves original
raw bytes and frozen strict assessments intact. Both new comparison arms use the
same repaired collector, so collector differences are not a treatment effect.
